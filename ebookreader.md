# In-app EPUB reader — coding brief

## Goal

Add an offline EPUB reader to Wombat Reader so users can open EPUBs created by the app and EPUBs chosen from device storage, read them in-app, and return to their saved reading position.

## Step 1 decision record

### First-release scope

- **Open last created EPUB** from the EPUB creation result.
- **Open EPUB** from device storage through Android's document picker.
- **Read reflowable EPUBs** in paginated mode, with swipe and previous/next navigation.
- Show title, a lightweight progress indicator, and a table of contents.
- Provide font-size plus light, dark, and sepia themes.
- Restore each book's last reading position.
- Keep all reading and book content offline.

### Deferred from the first release

- Bookmarks, highlights/annotations, search, TTS, cloud sync, DRM, a full bookshelf, and PDF/comic reading.
- Continuous scrolling as a user preference; it can follow after paginated reading is stable.

### Interaction map

```text
Create EPUB ──> Open in Wombat Liberates ──> ReaderActivity
                                              ├─ next/previous or swipe
                                              ├─ Aa menu: font size and theme
                                              ├─ Contents: select chapter
                                              └─ Back: return to main app

Main app ──> Open EPUB ──> Android document picker ──> ReaderActivity
```

### First-release manual acceptance

1. Create or select an EPUB and open it without network access.
2. Read through pages, select a chapter, and change font size/theme.
3. Close and reopen the same book at the saved location.
4. Confirm OCR capture, cleanup, and export behavior are unchanged.


## Recommended foundation

Use the Readium Kotlin toolkit:

- Native Android/Kotlin integration
- EPUB 2 and EPUB 3 support
- Reflowable reading, pagination/scrolling, table of contents, preferences, search, highlights, and TTS capabilities
- BSD-3-Clause license

Readium supplies the EPUB parser and navigator, not a finished reader screen. Wombat Liberates owns the reader UI, storage, and user experience.

## Non-negotiable constraints

- Reading must work offline for locally stored EPUBs.
- Never send EPUB/book text to a server merely to render it.
- Do not add DRM support in the first version.
- Preserve the existing EPUB export workflow.
- Keep created EPUBs available to the user even if an in-app copy is later cleared.
- Do not alter raw OCR or cleaned OCR while opening or reading an EPUB.

## Implementation and verification checklist

### [x] 1. Confirm scope and reader interaction design

**Work**

- Define the first-release reader features: open generated EPUB, open selected EPUB, previous/next navigation, chapter list, font size, theme, and saved position.
- Explicitly defer bookmarks, annotations, search, TTS, library metadata editing, and sync unless needed for the first release.
- Decide whether the initial navigation mode is paginated, scrolling, or user-selectable.

**Success conditions**

- The first-release scope is written down and does not silently expand into a full library product.
- The reader has clear entry points from EPUB creation and from a separate **Open EPUB** action.

**Tests**

- Product walkthrough with wireframes or a simple interaction map.
- Manual acceptance list approved before implementation starts.

### [ ] 2. Add Readium dependencies in a compatibility spike

**Work**

- Add the required Readium modules, initially `readium-shared`, `readium-streamer`, and `readium-navigator`.
- Pin a Readium version compatible with the project’s Android Gradle Plugin, Kotlin, min SDK, and compile SDK.
- Build a minimal internal screen that opens a known valid local EPUB using Readium’s parser and navigator.

**Success conditions**

- The app builds with the Readium dependencies.
- A valid EPUB opens without network access or DRM dependencies.
- An invalid/non-EPUB file produces a clear error rather than a crash.

**Tests**

- `./gradlew :app:assembleDebug`.
- Instrumented smoke test: valid EPUB opens; invalid ZIP/text file fails gracefully.
- Dependency/license review recorded in the implementation notes.

### [ ] 3. Define local EPUB storage and document access

**Work**

- Keep a private app copy of every EPUB generated by Wombat Liberates before/while exporting it through Android’s file picker.
- Add an **Open EPUB** action using Android’s document picker for externally selected files.
- Persist URI permission where Android grants it, and provide a useful message if access expires.
- Create a stable local book identifier for reading position/preferences.

**Success conditions**

- A newly created EPUB can be opened immediately in-app.
- A user can select and open an existing local EPUB.
- Reopening works after an app restart when file access remains available.
- The existing exported EPUB file remains unchanged.

**Tests**

- Instrumented tests for generated-private EPUB opening and `ACTION_OPEN_DOCUMENT` URI handling.
- Manual device test: create EPUB → open in reader → export/share it → open it again.
- Negative test: revoked/missing URI access shows recoverable guidance.

### [ ] 4. Build `ReaderActivity` around the Readium navigator

**Work**

- Add a dedicated `ReaderActivity` with a loading/error state and a full-screen EPUB navigator.
- Accept a book identifier or content URI through a typed intent contract.
- Handle activity rotation and process recreation without losing the open publication.
- Provide a clear Back action to return to the main workflow.

**Success conditions**

- Opening a supported EPUB reaches a readable first page.
- Loading, unsupported format, corrupt EPUB, and missing-file states are understandable.
- Rotation does not crash or reopen the wrong book.

**Tests**

- Instrumented tests for intent inputs, loading/error states, and activity recreation.
- Manual device test on a generated EPUB and a separately imported EPUB.

### [ ] 5. Add basic reading controls

**Work**

- Add previous/next page controls or swipe navigation.
- Add a reader menu with font-size controls and light/dark/sepia theme options.
- Display the title and a minimal progress indicator.
- Keep controls accessible with touch targets, content descriptions, and readable contrast.

**Success conditions**

- Users can move through chapters/pages and adjust text size/theme without reopening the book.
- Controls do not cover content permanently and can be reached with TalkBack.
- The reader remains usable in portrait and landscape.

**Tests**

- Instrumented navigation tests for previous/next behavior.
- Screenshot/manual device tests across themes, font sizes, and orientations.
- Accessibility scanner/TalkBack manual pass for labels and focus order.

### [ ] 6. Add table of contents navigation

**Work**

- Read the EPUB table of contents through Readium.
- Present a chapter/section list in a bottom sheet or side panel.
- Navigate to a selected entry and update progress correctly.

**Success conditions**

- EPUBs generated by Wombat Liberates show their chapter headings.
- EPUBs without a usable table of contents degrade gracefully.
- Selecting a chapter opens the intended location.

**Tests**

- Instrumented test using a generated multi-chapter EPUB.
- Fixture test with a valid EPUB lacking a table of contents.
- Manual test with long chapter names and nested entries.

### [ ] 7. Persist reading location and preferences

**Work**

- Save Readium locators keyed by stable book identifier.
- Save reader preferences such as font size, theme, and navigation mode locally.
- Restore the last location when reopening the same book.
- Offer an explicit **Start from beginning** action.

**Success conditions**

- Closing and reopening a book returns to the last position.
- Different books retain independent positions.
- Changing a preference updates the reader immediately and persists across restart.
- Replacing a book file with incompatible content fails safely rather than opening an incorrect position.

**Tests**

- Instrumented tests for locator persistence, separate-book isolation, app recreation, and reset-to-start.
- Manual test: read to several locations, force-close app, reopen, and verify position.

### [ ] 8. Add first-release library/opening UX

**Work**

- Add a small **Recent books** list for generated/opened EPUBs with title, author if available, and progress.
- Include **Open EPUB**, **Open last created EPUB**, and **Remove from recents** actions.
- Removing from recents must not delete the user’s externally saved EPUB; make private-copy deletion explicit and separate.

**Success conditions**

- Users can find recently opened/generated books without repeating file selection.
- Removing an item is clearly scoped and cannot accidentally delete external files.
- Empty-state guidance explains how to create or open a book.

**Tests**

- Instrumented tests for recents ordering, removal, and app restart persistence.
- Manual test confirming an external EPUB remains intact after removal from recents.

### [ ] 9. Add optional capabilities after the core reader is stable

**Work**

- Evaluate Readium search, bookmarks/highlights, TTS, and additional typography controls.
- Add one feature at a time with its own storage and privacy design.
- Do not conflate annotations with OCR correction rules.

**Success conditions**

- Each optional feature is independently useful, tested, and can be disabled without breaking reading.
- TTS and annotations remain on-device unless the user explicitly requests synchronization later.

**Tests**

- Feature-specific unit/instrumented tests.
- Manual regression pass ensuring core reading still works when optional features are unavailable.

### [ ] 10. Release readiness

**Work**

- Test generated EPUBs, imported EPUBs, malformed EPUBs, and large EPUBs.
- Test offline mode, rotation, background/foreground transitions, and app restart.
- Review dependency licenses and APK size/performance impact.
- Inspect the final diff and preserve unrelated user files.

**Success conditions**

- Reader opens supported books reliably offline and fails safely for unsupported input.
- No regression to OCR capture, cleanup, EPUB export, or existing settings.
- Build, automated tests, and manual device acceptance pass.

**Tests**

- `./gradlew :app:testDebugUnitTest :app:assembleDebug`.
- Instrumented reader suite on at least one physical device.
- Manual acceptance: create EPUB → open → navigate → change font/theme → close → reopen at saved location → export/open externally.
- `git diff --check` and final staged-file review before commit.

## Suggested delivery order

1. Steps 1–4: prove a generated EPUB can open in a minimal native reader.
2. Steps 5–7: make it pleasant and persistent.
3. Step 8: add the recent-books/opening experience.
4. Step 9: add search, bookmarks, or TTS only after the core reader is dependable.
5. Step 10: release verification.
